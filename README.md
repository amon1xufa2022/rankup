# RankUp — отчёты на повышение с входом через Discord

Сайт, где участник вашего Discord-сервера оставляет **отчёт на повышение**, а рассматривают его люди с ролью **«Инструктор» и выше**. После одобрения итог автоматически публикуется в указанный Discord-канал **по вебхуку**.

**Возможности**

- 🔐 Вход только через Discord (OAuth2, scopes `identify` + `guilds.members.read`) — без регистраций и паролей
- 📝 Форма отчёта полностью настраивается на сайте: поля, типы, обязательность, варианты (например, список рангов), порядок
- 🛡️ Ролевая иерархия: вы указываете ID ролей и уровни — кто с какого уровня одобряет отчёты, а кто управляет сайтом
- ✅ Очередь на одобрение с кнопками «Одобрить» / «Отклонить» и комментарием
- 📨 Вебхук: после одобрения красивое embed-сообщение с итогом прилетает в ваш канал
- ⚙️ Панель «Управление сайтом» прямо на сайте: поля, роли, уровни, вебхук, название, статистика, журнал событий
- 🎮 Демо-режим для предпросмотра без ключей Discord

## Быстрый старт (локально, с предпросмотром)

```bash
cd rankup
npm install
cp .env.example .env     # Windows: copy .env.example .env
```

Чтобы посмотреть интерфейс без ключей Discord, в `.env` поставьте `DEMO_MODE=true`, затем:

```bash
npm start
```

Откройте http://localhost:3000 — вверху появится жёлтая лента с тремя кнопками входа (Игрок / Инструктор / Администратор).

> ⚠️ `DEMO_MODE=true` — только для предпросмотра на своей машине. На боевом сервере выставьте `DEMO_MODE=false`, иначе любой посетитель сможет войти как админ.

## Подключение реального Discord-сервера

### Шаг 1. Создайте приложение

1. Откройте https://discord.com/developers/applications → **New Application**
2. Задайте имя (например, `RankUp повышения`) → Create

### Шаг 2. Ключи OAuth2

1. Слева: **OAuth2** → **General**
2. Скопируйте **Client ID** и **Client Secret** (кнопка Reset Secret, если нужен новый)
3. В **Redirects** нажмите **Add Redirect** и впишите **в точности**:
   ```
   http://localhost:3000/auth/discord/callback
   ```
   Для боевого сервера добавьте ещё и продакшн-адрес:
   ```
   https://ваш-домен.ru/auth/discord/callback
   ```
   (и укажите его в `.env` как `DISCORD_REDIRECT_URI`)
4. **Save Changes**

> ❌ Scopes в портале включать НЕ нужно — сайт сам запрашивает `identify guilds.members.read`.

### Шаг 3. Узнайте ID сервера и ролей

1. В Discord: **Настройки пользователя → Расширенные → Режим разработчика** — включить
2. **ПКМ по иконке сервера → Копировать ID сервера** → это `Guild ID`
3. **ПКМ по роли** (Настройки сервера → Роли) **→ Копировать ID роли** — для каждого уровня иерархии (Инструктор, Старший инструктор, Администратор…)

### Шаг 4. Вебхук канала

1. На сервере: **ПКМ по каналу → Настройки канала → Интеграции → Вебхуки → Новый вебхук**
2. Имя и аватар — любые (или задайте «Имя отправителя» на сайте, оно важнее)
3. **Копировать URL вебхука** → вставите на сайт в «Управлении» → «Вебхук»

### Шаг 5. Заполните .env

```env
PORT=3000
SESSION_SECRET=длинная-случайная-строка-например-64-символа
DISCORD_CLIENT_ID=вставьте сюда
DISCORD_CLIENT_SECRET=вставьте сюда
DISCORD_REDIRECT_URI=http://localhost:3000/auth/discord/callback
GUILD_ID=ID вашего сервера
ADMIN_DISCORD_IDS=ваш_discord_id   # через запятую, если несколько — полный доступ всегда
DEMO_MODE=false
```

> `ADMIN_DISCORD_IDS` — страховка для первой настройки: эти пользователи всегда админы, даже пока иерархия пуста. Свой Discord ID: включите Режим разработчика → ПКМ по себе в любом чате → «Копировать ID».

Запустите:

```bash
npm start
```

### Шаг 6. Настройте всё на самом сайте

Войдите через Discord под своим ID из `ADMIN_DISCORD_IDS` → вкладка **«Управление»**:

| Раздел | Что настроить |
|---|---|
| **Обзор** | Статистика: сколько заявок всего/ожидают/одобрено/отклонено + журнал событий |
| **Поля и ранги** | Названия полей формы, типы (текст/число/дата/ссылка/список), обязательность, **варианты выбора (ранги)** — каждый с новой строки. Порядок меняется стрелками ↑↓ |
| **Роли Discord** | Guild ID, строки иерархии (уровень → название → ID роли → цвет), минимальный уровень для одобрения (по умолчанию 2 = «Инструктор») и минимальный уровень для этой панели (по умолчанию 4 = «Администратор») |
| **Вебхук** | URL вебхука + кнопка «Тестовое сообщение» — сразу увидите, всё ли верно |
| **Сайт** | Название и подзаголовок; внизу — сброс настроек к умолчаниям |

### Как считается доступ

- Пользователь входит через Discord → сайт получает его роли на указанном сервере (`GET /users/@me/guilds/{guild.id}/member` со scope `guilds.members.read`)
- Берётся **наибольший уровень** среди его ролей по вашей иерархии
- `уровень ≥ «Мин. уровень одобрения»` → видит вкладку «Одобрение»
- `уровень ≥ «Мин. уровень управления»` → видит вкладку «Управление»
- ID роли пустой → роль не учитывается; роли с разных уровней не конфликтуют, побеждает высшая

## Как это выглядит (поток)

1. Участник открывает сайт → «Войти через Discord» → подтверждает доступ
2. Вкладка «Отчёт на повышение» → заполняет форму (ранг «из → в», что сделано, ссылка) → «Отправить»
3. Инструктор+ видит заявку во вкладке «Одобрение» → «Одобрить» / «Отклонить» (+ комментарий)
4. При одобрении итог-embed прилетает в ваш канал: кто, что просил, что написал, кто одобрил, когда

## Продакшн (боевой сервер)

- Поставьте за HTTPS (Caddy / Nginx / Cloudflare Tunnel) — иначе Discord не примет редирект и браузер не даст поставить secure-cookie
- В `.env`: `DISCORD_REDIRECT_URI=https://ваш-домен/auth/discord/callback`, `DEMO_MODE=false`, свой `SESSION_SECRET`, `NODE_ENV=production`
- В портале Discord добавьте **тот же** production-Redirect (шаг 2.3)
- Node.js 18+ (обязательно глобальный `fetch`)
- Данные хранятся в JSON-файлах в папке `data/` (создаётся автоматически) — делайте бэкап этой папки; процесс рассчитан на один инстанс

## Частые вопросы

**«Ошибка 401 при входе»** → проверьте, что `DISCORD_REDIRECT_URI` в `.env` символ-в-символ совпадает с Redirect в портале Discord.

**«Роли не видны / все уровни 0»** → проверьте `Guild ID` в «Управлении» → «Роли Discord» (15–25 цифр) и что ID ролей скопированы именно с вашего сервера. Также пользователь должен быть на этом сервере.

**«Вебхук не отправляется»** → нажмите «Тестовое сообщение» в «Вебхук». Если Discord отвечает 404 — вебхук удалён, создайте новый. 401/403 — URL повреждён при копировании.

**«Хочу другие ранги/звания»** → «Управление» → «Поля и ранги» → у поля типа «Выпадающий список» впишите свои варианты, каждый с новой строки → «Сохранить поля».
