Отчёт на повышение

Заполните форму — заявка уйдёт на рассмотрение Инструктору и выше.

Как быстро рассмотрят?

  • 1Заявка попадает в очередь «Одобрение» у всех Инструкторов и выше.
  • 2Инструктор проверяет отчёт и нажимает «Одобрить» или «Отклонить».
  • 3После одобрения итог автоматически публикуется в Discord-канал по вебхуку.
Чем конкретнее отчёт и чем больше доказательств — тем выше шанс быстрого одобрения.

Поля формы отчёта

Названия, типы, обязательность и варианты выбора (ранги). Порядок меняется стрелками.

Подключение к серверу Discord

Discord → Настройки → Расширенные → Режим разработчика, затем ПКМ по иконке сервера → «Копировать ID сервера».

Иерархия ролей

Чем выше уровень — тем больше прав. «Инструктор и выше» одобряют отчёты. ID роли копируется так же: ПКМ по роли в настройках сервера.

Минимальные уровни доступа

Пустой ID роли = роль не участвует в проверке. Пользователь с несколькими ролями получает наибольший уровень. Супер-админы из ADMIN_DISCORD_IDS имеют доступ всегда.

Вебхук Discord-канала

Канал → шестерёнка → Интеграции → Вебхуки → Новый вебхук → «Копировать URL вебхука». После одобрения отчёта сюда автоматически прилетит итог.
